# Community code of conduct

Be respectful, specific, and constructive. People of all backgrounds and experience levels are welcome.

Harassment, discrimination, threats, doxxing, sexual harassment, and sharing private data without consent are unacceptable. Critique ideas and code, not people. Respect a request to stop an interaction.

This policy covers project issues, pull requests, discussions, and other official project spaces. Maintainers may edit or remove content, lock discussions, or restrict participation. They should apply these rules fairly, explain decisions when appropriate, and protect reporters' privacy.

Report concerns using a private channel listed on the repository owner's public profile if available. Otherwise, ask for a private contact channel without naming affected people or publishing sensitive details. Maintainers involved in a report should not decide its outcome. There is no guaranteed response time.
